Optic Sketch: help

This tool is for rapidly sketching optical designs, which can then be exported to other tools for rigorous analysis. It is a sketchpad, not a design code: check anything that matters elsewhere. Bugs may abound!

Keys and mouse

Features

    Extensions

    Python scripts that add tabs to the beam and surface popups, or export formats to the File menu. The .py files in the extensions folder next to this page are loaded by default; others can be loaded from anywhere. They run in your browser (Pyodide, loaded from jsDelivr the first time one is used), sandboxed: a script sees the design it's given but not this page, its storage, or your files. Still, load only scripts you trust. See the README for the interface.
